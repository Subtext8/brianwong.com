# Amazon Bedrock

## Description
A fully-managed service that offers a choice of high-performing foundation models (FMs) to build generative AI applications, simplifying development while maintaining privacy and security.

## From [[Wiki/Sources/Retrieval-Augmented Generation]]
- Knowledge bases for Amazon Bedrock allow connecting FMs to data sources for RAG in a few clicks, automating vector conversions, retrievals, and output generation.
