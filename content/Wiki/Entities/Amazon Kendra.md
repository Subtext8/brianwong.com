# Amazon Kendra

## Description
A highly-accurate enterprise search service powered by machine learning, providing an optimized Retrieve API for RAG workflows.

## From [[Wiki/Sources/Retrieval-Augmented Generation]]
- Provides a high-accuracy semantic ranker as an enterprise retriever.
- Supports retrieving up to 100 semantically-relevant passages.
- Includes pre-built connectors to data sources like S3, SharePoint, and Confluence.
- Supports various document formats (HTML, Word, PDF, etc.) and respects end-user permissions.
