# MCP (Model Context Protocol)

Universal adapter for AI agents/tools: Standardizes connections to external services (USB for AI).

**From** [[Wiki/Sources/10-AI-Concepts]]

- Open protocol by [[Wiki/Entities/Anthropic|Anthropic]], donated to [[Wiki/Entities/Agentic AI Foundation|Agentic AI Foundation]] (Linux Foundation).

## From [[Wiki/Sources/Is Ontology the AI Breakthrough That Actually Threatens Jobs|Is Ontology the AI Breakthrough That Actually Threatens Jobs]]
- Standardises how AI apps connect to external resources, tools and prompts — no hard-coding each integration; discovery through a common interface.
- Limit: "MCP can give the AI the phone numbers. But it doesn't necessarily give it the organisation chart." Agents still face which Salesforce customer = which SAP account, what "active" means per system, which system is authoritative, what actions are permitted.
- Composes with [[Wiki/Concepts/Ontology|ontology]]: MCP becomes the interface through which agents reach ontology-backed resources and actions.
